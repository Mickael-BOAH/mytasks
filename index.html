Como criar o Firebase

  1. Vai a console.firebase.google.com
  2. Clica "Criar um projeto"
  3. No projeto, clica em </> (Web)
  4. Copia o objeto firebaseConfig
  5. Vai a Firestore → Criar base de dados → Modo de teste
  6. Cola aqui e clica Ligar

Para acesso permanente nas Regras: allow read, write: if true;

Ligar ao Google

  1. Vai a console.cloud.google.com
  2. Seleciona o mesmo projeto do Firebase
  3. APIs e serviços → Ativar APIs: Calendar API e Gmail API
  4. Credenciais → Criar credencial → ID cliente OAuth → App Web
  5. Em "Origens autorizadas" adiciona http://localhost:3000
  6. Copia o ID do cliente e cola acima
